## Rules
1. All the AI generated content must be done on the `scratch/` directory
2. The content of the `refs/` directory is meant to be used as references, not to be edited
3. The content of the `notes/` directory is informal and does not need references, but the math should be correct
4. The content of the `src/` directory is for the main paper, should be formal and needs references
5. The workflow is write → commit → review → correct → commit → write → commit → ...
